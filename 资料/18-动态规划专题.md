## 1. 背包问题

### 1.1 01 背包

**适用**：每件物品选 0/1 次。
**思路**：`f[j]` = 容量 `j` 下的最大价值，**倒序**枚举容量避免重复选。

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n, V;
    scanf("%d %d", &n, &V);
    vector<int> f(V + 1, 0);
    for (int i = 1; i <= n; ++i) {
        int w, v;
        scanf("%d %d", &w, &v);
        for (int j = V; j >= w; --j) f[j] = max(f[j], f[j - w] + v);   // 倒序
    }
    printf("%d\n", f[V]);
    return 0;
}
```

### 1.2 完全背包

**思路**：每件物品无限次，容量**正序**枚举。

```cpp skip
// 与 01 背包唯一区别：内层容量改为正序
for (int j = w; j <= V; ++j) f[j] = max(f[j], f[j - w] + v);          // 正序
```

### 1.3 多重背包（二进制拆分 / 单调队列）

**实例：P1776 宝物筛选** —— 每件物品有限个。

```cpp
#include <bits/stdc++.h>
using namespace std;

// 二进制拆分：把 cnt 个物品拆成 1,2,4,...,剩下的 个"0/1 物品"
int main() {
    int n, V;
    scanf("%d %d", &n, &V);
    vector<int> f(V + 1, 0);
    for (int i = 0; i < n; ++i) {
        int w, v, c;
        scanf("%d %d %d", &w, &v, &c);
        for (int k = 1; k <= c; k <<= 1) {
            c -= k;
            int W = k * w, Val = k * v;
            for (int j = V; j >= W; --j) f[j] = max(f[j], f[j - W] + Val);
        }
        if (c) {
            int W = c * w, Val = c * v;
            for (int j = V; j >= W; --j) f[j] = max(f[j], f[j - W] + Val);
        }
    }
    printf("%d\n", f[V]);
    return 0;
}
```

> 多重背包的**单调队列优化** `O(nV)` 见 [30-DP 优化](30-DP优化-单调队列斜率决策单调.md)。

### 1.4 分组背包 / 依赖背包

**实例：P1064 金明的预算方案**（主件 + 附件，附件依赖主件）。

```cpp skip
// 伪代码：把"主件 + 其附件的子集"预处理成若干"组内物品"，再做分组背包
// 状态：f[j] 容量 j 的最大价值；每组（主件）内只能选一种组合
for (每个主件) {
    for (int j = V; j >= 0; --j) {
        for (auto &[w, v] : 该组的所有合法组合) {
            if (j >= w) f[j] = max(f[j], f[j - w] + v);
        }
    }
}
```

### 1.5 背包的计数 / 方案数

**实例：P1164 小A点菜** —— 求恰好花完 `m` 元的方案数。

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {

}
```

## 2. 线性 DP

### 2.1 最长上升子序列 LIS

**实例：P1020 / P1439**

```cpp
#include <bits/stdc++.h>
using namespace std;

// O(n log n)：f[i] = 长度为 i 的上升子序列的最小结尾
int lis(const vector<int> &a) {                // 严格上升
    vector<int> f;
    for (int x : a) {
        auto it = lower_bound(f.begin(), f.end(), x);   // 非降用 upper_bound
        if (it == f.end()) f.push_back(x);
        else *it = x;
    }
    return (int)f.size();
}
```

**为什么对**：贪心地让每个长度的结尾尽量小，给后面留余地。

**变形**：
- 最长不下降子序列 → `upper_bound`
- 最长下降 → 取负 / 反转后求 LIS
- **LIS 计数**、**输出方案** → 用树状数组维护 `(长度, 方案数)`

### 2.2 最长公共子序列 LCS

```cpp
#include <bits/stdc++.h>
using namespace std;

// O(nm)
int lcs(const string &a, const string &b) {
    int n = (int)a.size(), m = (int)b.size();
    vector<vector<int>> f(n + 1, vector<int>(m + 1, 0));
    for (int i = 1; i <= n; ++i)
        for (int j = 1; j <= m; ++j)
            f[i][j] = (a[i - 1] == b[j - 1]) ? f[i - 1][j - 1] + 1
                                             : max(f[i - 1][j], f[i][j - 1]);
    return f[n][m];
}
// 若两串都是 1..n 的排列，可转成 LIS（O(n log n)）
```

### 2.3 最大子段和 / 最大子矩阵

```cpp
#include <bits/stdc++.h>
using namespace std;

// 最大子段和 O(n)
long long max_subarray(const vector<long long> &a) {
    long long best = LLONG_MIN / 4, cur = 0;
    for (long long x : a) { cur = max(cur + x, x); best = max(best, cur); }
    return best;
}

// 最大子矩阵和 O(n^2 m)：枚举行的上下界，压成一维数组再求最大子段和
long long max_submatrix(const vector<vector<long long>> &a) {
    int n = (int)a.size(), m = (int)a[0].size();
    long long best = LLONG_MIN / 4;
    for (int top = 0; top < n; ++top) {
        vector<long long> col(m, 0);
        for (int bot = top; bot < n; ++bot) {
            for (int j = 0; j < m; ++j) col[j] += a[bot][j];
            best = max(best, max_subarray(col));
        }
    }
    return best;
}
```

### 2.4 编辑距离

```cpp
#include <bits/stdc++.h>
using namespace std;

// 插入/删除/替换各代价 1
int edit_distance(const string &a, const string &b) {
    int n = (int)a.size(), m = (int)b.size();
    vector<vector<int>> f(n + 1, vector<int>(m + 1));
    for (int i = 0; i <= n; ++i) f[i][0] = i;
    for (int j = 0; j <= m; ++j) f[0][j] = j;
    for (int i = 1; i <= n; ++i)
        for (int j = 1; j <= m; ++j)
            f[i][j] = min({f[i - 1][j] + 1, f[i][j - 1] + 1,
                           f[i - 1][j - 1] + (a[i - 1] != b[j - 1])});
    return f[n][m];
}
```

## 3. 区间 DP

**适用**：问题可以"合并两个相邻区间"得到大区间。
**状态**：`f[l][r]` = 区间 `[l,r]` 的答案。
**转移**：枚举分割点 `k`：`f[l][r] = min/max(f[l][k] + f[k+1][r] + cost(l,k,k+1,r))`。
**遍历顺序**：**先枚举区间长度**。

```cpp
#include <bits/stdc++.h>
using namespace std;

// 石子合并（P1880）：环形，求最小合并代价
int main() {
    int n;
    scanf("%d", &n);
    vector<int> a(2 * n + 1), pre(2 * n + 1, 0);
    for (int i = 1; i <= n; ++i) { scanf("%d", &a[i]); a[i + n] = a[i]; }
    for (int i = 1; i <= 2 * n; ++i) pre[i] = pre[i - 1] + a[i];

    vector<vector<int>> f(2 * n + 1, vector<int>(2 * n + 1, 0));
    for (int len = 2; len <= n; ++len)                 // 长度
        for (int l = 1; l + len - 1 <= 2 * n; ++l) {   // 左端点
            int r = l + len - 1;
            for (int k = l; k < r; ++k)                // 分割点
                f[l][r] = max(f[l][r], f[l][k] + f[k + 1][r] + pre[r] - pre[l - 1]);
        }
    int ans = 0;
    for (int l = 1; l <= n; ++l) ans = max(ans, f[l][l + n - 1]);
    printf("%d\n", ans);
    return 0;
}
```

> **环形**处理：复制一遍变 `2n`，答案取 `[i, i+n-1]` 的最大值。

**实例：P1063 能量项链** —— 环形区间 DP，边为"珠子"，转移时乘上三个端点。

```cpp
// 状态：f[l][r] 表示合并 [l,r] 珠子的最大能量
// 转移：f[l][r] = max(f[l][k] + f[k+1][r] + a[l]*a[k+1]*a[r+1])
```

**实例：P1220 关路灯** —— 区间 DP 带"当前位置"（左端/右端），扩展区间。

## 4. 树形 DP

**适用**：状态依赖子树结构。
**套路**：`f[u][...]` 由儿子合并而来；DFS 后序处理。

### 4.1 没有上司的舞会（P1352）

```cpp
#include <bits/stdc++.h>
using namespace std;

int n;
vector<vector<int>> g;
vector<int> val, fa;
vector<array<long long,2>> f;              // f[u][0] 不选 u, f[u][1] 选 u

void dfs(int u) {
    f[u][0] = 0;
    f[u][1] = val[u];
    for (int v : g[u]) {
        dfs(v);
        f[u][0] += max(f[v][0], f[v][1]);  // 不选 u，儿子随意
        f[u][1] += f[v][0];                // 选 u，儿子必不选
    }
}

int main() {
    scanf("%d", &n);
    val.assign(n + 1, 0);
    fa.assign(n + 1, 0);
    g.assign(n + 1, {});
    f.assign(n + 1, {0, 0});
    for (int i = 1; i <= n; ++i) scanf("%d", &val[i]);
    for (int i = 1; i < n; ++i) {
        int u, v;
        scanf("%d %d", &u, &v);
        fa[u] = v;
        g[v].push_back(u);
    }
    int root = 1;
    while (fa[root]) root = fa[root];
    dfs(root);
    printf("%lld\n", max(f[root][0], f[root][1]));
    return 0;
}
```

### 4.2 树形背包（P2014 选课 / P1273 有线电视网）★

**思路**：`f[u][j]` = 以 `u` 为根的子树中选 `j` 个节点的最大收益。合并儿子时做**分组背包**，注意**倒序**枚举 `j`。

```cpp
#include <bits/stdc++.h>
using namespace std;

// f[u][j]：在 u 的子树中选 j 个点的最大收益
// 依赖：g 邻接表，sz[u] 子树大小
struct TreeKnapsack {
    int n, cap;
    vector<vector<int>> g;
    vector<int> sz;
    vector<vector<long long>> f;
    static constexpr long long NEG = -1e18;

    TreeKnapsack(int n_, int cap_) : n(n_), cap(cap_), g(n_ + 1), sz(n_ + 1),
        f(n_ + 1, vector<long long>(cap_ + 1, NEG)) {}

    void addEdge(int u, int v) { g[u].push_back(v); g[v].push_back(u); }

    void dfs(int u, int p) {
        sz[u] = 1;
        for (int v : g[u]) if (v != p) {
            dfs(v, u);
            // 合并 v 的子树：倒序 j，避免重复选
            for (int j = min(cap, sz[u] + sz[v]); j >= 1; --j)
                for (int k = 1; k <= min(sz[v], j); ++k)
                    if (f[u][j - k] > NEG / 2 && f[v][k] > NEG / 2)
                        f[u][j] = max(f[u][j], f[u][j - k] + f[v][k]);
            sz[u] += sz[v];
        }
    }
};
```

> **复杂度**：`O(n * cap^2)` 是上界，但实际因 `sz` 限制是 `O(n * cap)` 级别（经典结论）。

## 5. 状压 DP

**适用**：`n <= 20`，状态是"集合"。
**状态**：`f[mask]` 或 `f[mask][i]`（当前在 `i`）。

**实例：P1896 互不侵犯（状压）** —— `n*n` 棋盘放 `k` 个国王，互不攻击。

```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;

// 状压：每行状态 s，要求 s 内部无相邻 1；相邻行不能有竖直/斜向冲突
int main() {
    int n, K;
    scanf("%d %d", &n, &K);
    int full = 1 << n;
    vector<int> states;                      // 合法行状态
    vector<int> cnt;                         // 该状态放的国王数
    for (int s = 0; s < full; ++s) {
        if (s & (s << 1)) continue;          // 行内相邻
        states.push_back(s);
        cnt.push_back(__builtin_popcount((unsigned)s));
    }
    int m = (int)states.size();
    // f[i][s][k]：第 i 行状态 states[s]，共放 k 个
    // 滚动数组
    vector<vector<ll>> f(m, vector<ll>(K + 1, 0)), nf(m, vector<ll>(K + 1, 0));
    for (int s = 0; s < m; ++s) if (cnt[s] <= K) f[s][cnt[s]] = 1;
    for (int i = 1; i < n; ++i) {
        fill(nf.begin(), nf.end(), vector<ll>(K + 1, 0));
        for (int s = 0; s < m; ++s)
            for (int t = 0; t < m; ++t) {
                int a = states[s], b = states[t];
                if ((a & b) || ((a << 1) & b) || (a & (b << 1))) continue;   // 冲突
                for (int k = 0; k + cnt[t] <= K; ++k)
                    nf[t][k + cnt[t]] += f[s][k];
            }
        f.swap(nf);
    }
    ll ans = 0;
    for (int s = 0; s < m; ++s) ans += f[s][K];
    printf("%lld\n", ans);
    return 0;
}
```

**实例：P1433 吃奶酪** —— `f[mask][i]`：已吃 `mask`，最后在 `i` 的最短路程。

```cpp
// 转移：f[mask | 1<<j][j] = min(f[mask][i] + dis(i, j))
// 答案：min over i of f[full][i]
```

**实例：P1879 玉米田** —— 状压 + 障碍位，逐行转移。

**实例：P4363 一双木棋** —— 状压 + 博弈（min-max）搜索。

## 6. 数位 DP

**适用**：统计 `[L, R]` 中满足某种数位条件的数。
**套路**：`dfs(pos, 状态, limit)`，`limit` 表示是否贴住上界；**记忆化时不要记忆 `limit=true` 的状态**。

**实例：P2602 数字计数** —— 统计 `[a,b]` 中每个数字出现次数。

```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;

ll f[15][15];          // f[pos][cnt]：pos 位、该数字已出现 cnt 次的方案（非 limit）
int digit[15];

// 统计 [0, x] 中数字 d 出现次数
ll dfs(int pos, int cnt, bool limit, bool lead, int d) {
    if (pos == 0) return cnt;
    if (!limit && !lead && f[pos][cnt] >= 0) return f[pos][cnt];
    int up = limit ? digit[pos] : 9;
    ll res = 0;
    for (int i = 0; i <= up; ++i) {
        bool isLead = lead && i == 0;
        res += dfs(pos - 1, cnt + (!isLead && i == d), limit && i == up, isLead, d);
    }
    if (!limit && !lead) f[pos][cnt] = res;
    return res;
}

ll count_digit(ll x, int d) {
    if (x < 0) return 0;
    int len = 0;
    while (x) { digit[++len] = (int)(x % 10); x /= 10; }
    memset(f, -1, sizeof f);
    return dfs(len, 0, true, true, d);
}
```

**实例：P2657 windy 数** —— 相邻数位差 `>= 2`；状态带"上一个数位"。

**实例：P4124 手机号码** —— 状态带"是否有 4/8、连续 3 个相同"，记忆化 4 维。

**数位 DP 的坑**：
1. `limit` 状态**不能**记忆化（否则答案错）。
2. 前导零 `lead` 要单独处理（`0` 不能算作出现）。
3. 多测时**每次清空**记忆数组。
4. 返回 `[L,R]` 用 `solve(R) - solve(L-1)`。

## 7. 概率 / 期望 DP

**思路**：
- **期望线性性**：`E[X+Y] = E[X] + E[Y]`（无需求独立）。
- **正向推**（已知起点求终点）：`E[u] = 1 + Σ p * E[v]`。
- **反向推**（已知终点求起点）：常用于"期望步数"，从终态倒推。
- 有环时列方程 → 高斯消元。

**实例：P4316 绿豆蛙的归宿** —— DAG 上从 1 到 n 的期望路径长度。

## 8. DP 模型速查表

| 题面特征 | 模型 |
|---|---|
| 选/不选，有容量 | 背包 |
| 序列上的递推 | 线性 DP / LIS / LCS |
| 相邻合并、合并代价 | 区间 DP（按长度枚举） |
| 树上的选择 | 树形 DP / 树形背包 |
| `n <= 20`，集合状态 | 状压 DP |
| 数位条件计数 | 数位 DP |
| 概率/期望 | 概率 DP / 期望 DP |
| 计数方案 | 组合 + DP |
| 决策单调、`O(n^2)` 超时 | 斜率/单调队列/决策单调优化（见 30） |
| 环上的 DP | 破环成链 / 分类讨论 |

**通用调试技巧**：
1. **先写暴力 DP**，验证状态和转移。
2. 打印 `f` 数组前几行，手算对拍。
3. 检查**初始化**（`f[0][0]` 之类）和**边界**（`f[n]` 之外）。
4. 检查**遍历顺序**是否满足依赖（区间 DP 按长度，背包倒序/正序）。
