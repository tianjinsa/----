## 1. 偏序的定义与判定

**偏序关系** `≤` 在集合 `S` 上需满足：

1. **自反性**：`a ≤ a`
2. **反对称性**：`a ≤ b` 且 `b ≤ a` ⇒ `a = b`
3. **传递性**：`a ≤ b` 且 `b ≤ c` ⇒ `a ≤ c`

**严格偏序** `<`：反自反 + 传递（反对称自动成立）。

**判定模板**（`n` 小的时候）：

```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;

// 给定关系矩阵 rel[a][b] 表示 a <= b，判定是否构成偏序
bool is_partial_order(int n, const vector<vector<bool>> &rel) {
    // 自反
    for (int i = 1; i <= n; ++i) if (!rel[i][i]) return false;
    // 反对称
    for (int i = 1; i <= n; ++i)
        for (int j = 1; j <= n; ++j)
            if (rel[i][j] && rel[j][i] && i != j) return false;
    // 传递
    for (int i = 1; i <= n; ++i)
        for (int j = 1; j <= n; ++j) if (rel[i][j])
            for (int k = 1; k <= n; ++k)
                if (rel[j][k] && !rel[i][k]) return false;
    return true;
    // 复杂度 O(n^3)，n <= 500 可用；更大的用 bitset
}
```

**判定是否是"全序"**（任意两个元素可比）：`rel[i][j] || rel[j][i]` 对所有 `i != j` 成立。

## 2. 链与反链：Dilworth 定理 ★

设 `(P, ≤)` 是有限偏序集：

| 定理 | 内容 |
|---|---|
| **Dilworth** | **最小链覆盖数 = 最长反链大小** |
| **Mirsky（对偶）** | **最小反链覆盖数 = 最长链长度** |

其中：
- **链**：任意两元素可比的子集。
- **反链**：任意两元素不可比的子集。
- **链覆盖**：用若干条链覆盖所有元素。

**实战用法**：
- 题目问"最多能选多少个互不可比的元素" = **最长反链** = **最小链覆盖**，用 **二分图匹配** 求。
- 题目问"最少分成几组，每组内可比" = 最小链覆盖 = `n - 最大匹配`。
- 题目问"能不能分成 k 条链" = 最长反链 `<= k`。

```cpp
#include <bits/stdc++.h>
using namespace std;

// Dilworth：最小链覆盖。二分图建图：
// 把每个元素 i 拆成左 i 和右 i'，若 i < j（可比且 i != j）则连 i -> j'
// 答案 = n - 最大匹配
// 这里的"可比"由偏序 DAG 给出：若存在 i -> j 的路径（传递闭包），即 i < j

struct Dilworth {
    int n;
    vector<vector<int>> g;               // 偏序 DAG 的传递闭包
    vector<int> matchR, vis;
    int timer = 0;

    explicit Dilworth(int n_) : n(n_), g(n_ + 1), matchR(n_ + 1, 0), vis(n_ + 1, 0) {}
    void addComparable(int i, int j) { g[i].push_back(j); }   // i < j

    bool dfs(int u) {
        for (int v : g[u]) {
            if (vis[v] == timer) continue;
            vis[v] = timer;
            if (!matchR[v] || dfs(matchR[v])) { matchR[v] = u; return true; }
        }
        return false;
    }
    int min_chain_cover() {              // = 最长反链长度
        int m = 0;
        for (int i = 1; i <= n; ++i) { ++timer; if (dfs(i)) ++m; }
        return n - m;
    }
};
```

**注意**：`g` 必须是**传递闭包**（即 `i < j` 当且仅当存在路径）。如果原图只是"覆盖关系"，要先求传递闭包（Floyd / bitset）。

## 3. 偏序集上的最长链（DAG 最长路）

```cpp
#include <bits/stdc++.h>
using namespace std;

// 偏序 DAG 的最长链：拓扑排序 + DP
struct LongestChain {
    int n;
    vector<vector<int>> g;
    vector<int> indeg, dp;

    explicit LongestChain(int n_) : n(n_), g(n_ + 1), indeg(n_ + 1, 0), dp(n_ + 1, 1) {}
    void addEdge(int u, int v) { g[u].push_back(v); ++indeg[v]; }   // u < v

    int run() {
        queue<int> q;
        for (int i = 1; i <= n; ++i) if (!indeg[i]) q.push(i);
        int ans = 0, cnt = 0;
        while (!q.empty()) {
            int u = q.front(); q.pop(); ++cnt;
            ans = max(ans, dp[u]);
            for (int v : g[u]) {
                dp[v] = max(dp[v], dp[u] + 1);
                if (--indeg[v] == 0) q.push(v);
            }
        }
        return cnt == n ? ans : -1;      // -1 表示有环（不是偏序）
    }
};
```

> **有环 ⇒ 不是偏序**。所以"偏序 DAG 最长链"和"有向图最长路"的区别就是**先判环**（见 15 号文件）。

## 4. 二维偏序（排序 + 树状数组）

**问题**：给 `n` 个点 `(x_i, y_i)`，对每个点求有多少点满足 `x_j <= x_i` 且 `y_j <= y_i`。

```cpp
#include <bits/stdc++.h>
using namespace std;

// 二维数点：按 x 排序（x 相同按 y 排序），然后 BIT 统计前缀 y
// 若要求"严格小于"，排序时把 y 降序处理同 x 的组，或离线分组
struct Fenwick2D {
    int m;
    vector<int> t;
    explicit Fenwick2D(int m_) : m(m_), t(m_ + 1, 0) {}
    void add(int i, int v) { for (; i <= m; i += i & -i) t[i] += v; }
    int sum(int i) const { int s = 0; for (; i > 0; i -= i & -i) s += t[i]; return s; }
};

vector<int> count_dominated(vector<pair<int,int>> pts) {      // pts 0-based
    int n = (int)pts.size();
    vector<int> ys;
    for (auto &p : pts) ys.push_back(p.second);
    sort(ys.begin(), ys.end());
    ys.erase(unique(ys.begin(), ys.end()), ys.end());
    int m = (int)ys.size();
    auto yid = [&](int y) {
        return int(lower_bound(ys.begin(), ys.end(), y) - ys.begin()) + 1;
    };

    vector<int> ord(n);
    iota(ord.begin(), ord.end(), 0);
    sort(ord.begin(), ord.end(), [&](int a, int b) {
        if (pts[a].first != pts[b].first) return pts[a].first < pts[b].first;
        return pts[a].second < pts[b].second;
    });

    Fenwick2D bit(m);
    vector<int> res(n, 0);
    int i = 0;
    while (i < n) {
        int j = i;
        while (j < n && pts[ord[j]].first == pts[ord[i]].first) ++j;
        for (int k = i; k < j; ++k) res[ord[k]] = bit.sum(yid(pts[ord[k]].second));
        for (int k = i; k < j; ++k) bit.add(yid(pts[ord[k]].second), 1);
        i = j;
    }
    return res;
}
```

> **关键细节**：`x` 相同的点要**先查询整组、再整组插入**，避免同 `x` 互相贡献（如果题目要求严格偏序）。

## 5. 三维偏序：CDQ 分治 ★

**问题**：`n` 个点 `(a_i, b_i, c_i)`，对每个点求有多少 `j`（含自己）满足 `a_j <= a_i, b_j <= b_i, c_j <= c_i`。模板题：洛谷 P3810。

**思路**：

1. 按 `(a,b,c)` 排序后**去重**，合并重复个数 `cnt`。
2. **CDQ 分治**：`cdq(l, r)` 负责统计"左半对右半的贡献"（此时左半 `a` 全 `<=` 右半 `a`）。
3. 左右两半各自按 `b` 排序，**双指针**扫描：右半每个点，把左半所有 `b <= 它` 的点按 `c` 插入树状数组，然后查前缀和。
4. 递归必须先做（`cdq(l,mid)` / `cdq(mid+1,r)`），再做本层的双指针统计。

```cpp
#include <bits/stdc++.h>
using namespace std;

struct CDQ3D {
    struct Node { int a, b, c, cnt = 1, ans = 0; };
    vector<Node> p;
    vector<int> bit, touched;
    int CMAX = 0;

    void add(int i, int v) {
        for (; i <= CMAX; i += i & -i) { bit[i] += v; touched.push_back(i); }
    }
    int sum(int i) const {
        int s = 0;
        for (; i > 0; i -= i & -i) s += bit[i];
        return s;
    }
    void clear_bit() {
        for (int i : touched) bit[i] = 0;
        touched.clear();
    }

    void cdq(int l, int r) {
        if (l >= r) return;
        int mid = (l + r) >> 1;
        cdq(l, mid);
        cdq(mid + 1, r);

        vector<int> L, R;
        for (int i = l; i <= mid; ++i) L.push_back(i);
        for (int i = mid + 1; i <= r; ++i) R.push_back(i);
        auto byB = [&](int x, int y) { return p[x].b < p[y].b; };
        sort(L.begin(), L.end(), byB);
        sort(R.begin(), R.end(), byB);

        size_t j = 0;
        for (int id : R) {
            while (j < L.size() && p[L[j]].b <= p[id].b) {
                add(p[L[j]].c, p[L[j]].cnt);
                ++j;
            }
            p[id].ans += sum(p[id].c);
        }
        clear_bit();
    }

    // nodes: 输入点；cmax: c 的值域上界。返回去重后每个点的 ans（含自身重复 cnt）
    vector<int> solve(vector<Node> nodes, int cmax) {
        CMAX = cmax;
        bit.assign(CMAX + 2, 0);
        sort(nodes.begin(), nodes.end(), [](const Node &x, const Node &y) {
            if (x.a != y.a) return x.a < y.a;
            if (x.b != y.b) return x.b < y.b;
            return x.c < y.c;
        });
        p.clear();
        for (auto &x : nodes) {
            if (!p.empty() && p.back().a == x.a && p.back().b == x.b && p.back().c == x.c)
                p.back().cnt += x.cnt;
            else p.push_back(x);
        }
        int n = (int)p.size();
        if (n == 0) return {};
        cdq(0, n - 1);
        vector<int> res(n);
        for (int i = 0; i < n; ++i) res[i] = p[i].ans + p[i].cnt - 1;  // 去掉自身
        return res;
    }
};
```

**必须注意的 5 个坑**：

1. **先去重合并 `cnt`**，否则相同点互相干扰。
2. 先递归、后统计；统计用的 `b` 序必须是**索引副本**，不能原地打乱 `p`（`p` 的 `a` 序是分治前提）。
3. `add` 时把访问过的 BIT 下标记进 `touched`，清空时**置 0**（不要"减回去"，容易错）。
4. `ans` 要按 `cnt` 累加（重复点算多个）。
5. 若题目要**严格**偏序，改成 `p[L[j]].b < p[id].b` 且 `a` 相同的一组要整体处理。

**复杂度**：`O(n log^2 n)`。

**通用化**：若 `c` 值域很大，先离散化；若要求"三维严格小于"，把排序与比较改成严格版；若是"四维偏序"，外层再套一层 CDQ（`O(n log^3 n)`）。

## 6. 偏序题建模速查

| 题目说法 | 模型 |
|---|---|
| "最长上升子序列" | 二维偏序（下标 + 值） |
| "最多选多少个两两不.." | Dilworth（最长反链 = 最小链覆盖） |
| "最少分几组，组内可比" | 最小链覆盖 = `n - 最大匹配` |
| "三维偏序 / 陌上花开" | CDQ |
| "动态三维偏序" | CDQ 套 CDQ / 树套树 / 整体二分 |
| "区间包含关系" | 二维偏序（`l` 升序 + `r` 降序） |
| "矩形覆盖/数点" | 二维偏序 + 扫描线 |
| "偏序是否为全序" | 传递闭包后检查 |
| "偏序集高度" | DAG 最长路 |

**经典题**：P1020（LIS + Dilworth）、P3810（CDQ）、P3157（动态逆序对 = 三维偏序）、P2487（二维偏序 + 概率）。


### 怎么用（照抄这段 `main`，只改【输入】【输出】两处）

上面是模板本体。实际写题时：**把上面的 struct 整段粘过来 → 再粘这段 `main` → 只改标了【输入】【输出】的行**。

```cpp skip
#include <bits/stdc++.h>
using namespace std;

// ===== 粘贴点：把上面的 CDQ3D 粘到这里 =====

int main() {
    // ===================== 【输入】改这里 =====================
    int n, cmax;
    scanf("%d %d", &n, &cmax);            // 点数、第三维的值域上界
    vector<CDQ3D::Node> nodes(n);
    for (int i = 0; i < n; ++i)
        scanf("%d %d %d", &nodes[i].a, &nodes[i].b, &nodes[i].c);
    // ========================================================

    // ===================== 【核心】算法流程 =====================
    // CDQ 分治求三维偏序：
    //   1) 按 (a,b,c) 排序并去重，重复点合并成 cnt
    //   2) cdq(l, r)：递归处理左右两半的内部贡献
    //   3) 跨半贡献：此时左半 a 全 <= 右半 a
    //      左右各自按 b 排序，双指针把左半 b <= 当前右半点的按 c 塞进树状数组
    //      再查 c 的前缀和，就是这个右半点被多少个左半点支配
    //   4) 统计完把树状数组清空（用 touched 记录，不要 memset）
    CDQ3D cdq;
    vector<int> ans = cdq.solve(nodes, cmax);
    // ========================================================

    // ===================== 【输出】改这里 =====================
    for (int i = 0; i < (int)ans.size(); ++i)
        printf("%d%c", ans[i], " \n"[i + 1 == (int)ans.size()]);
    // ========================================================
    return 0;
}
```

## 7. 思路与例题索引

| 算法 | 思路一句话 | 用途 | 例题 |
|---|---|---|---|
| 偏序判定 | 自反 + 反对称 + 传递 | 关系是否合法 | P1887 三元上升子序列（变体） |
| Dilworth | 最小链覆盖 = 最长反链 = `n - 最大匹配` | 最多选多少个互不可比 | P1020 导弹拦截（第二问） |
| DAG 最长链 | 拓扑排序 + DP | 偏序集高度 | P1807 最长路 |
| 二维偏序 | 按 x 排序 + BIT 查 y 前缀 | 数点、逆序 | P1908、P3608 |
| CDQ 三维偏序 | 分治 + 双指针 + BIT，先递归后统计 | 三维数点 | P3810【模板】陌上花开 |
| 传递闭包 | Floyd / bitset | 可达性、判全序 | P2419 Cow Contest |
| LIS | 贪心 + 二分（等价二维偏序） | 最长上升子序列 | P1020、P1439 |

**关键**：CDQ 要先去重合并 `cnt`，且 `b` 的排序要用索引副本。
