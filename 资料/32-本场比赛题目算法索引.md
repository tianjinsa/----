## 1. A. All Closed —— 线性基传播

**题目要求**：给 `n` 个集合，每次操作把一个数 `x` 加进所有不含它的集合，求最少操作次数并构造。

**算法点**：

1. **异或封闭 = 线性子空间**。集合对异或封闭 ⟺ 它是 `F₂^m` 上的线性子空间。
2. **强制插入**：维护公共线性空间 `V`，局部空间 `U_i = span(S_i ∪ V)`，则 `U_i \ S_i` 必须插入。
3. **不动点迭代**：把新元素并入 `V`，再传播给所有局部空间，直到不变。
4. **摊还优化**：若 `|U_i| > 2|S_i|`，则缺失元素能张成整个 `U_i` → 直接吸收整个基，不再维护。
5. **答案**：`X = V \ ∩ S_i`（用出现次数 `frequency[x] != n` 判断）。

**核心模板**（[29-§3](29-线性代数与博弈论.md) 的 `LinearBasis`）：

```cpp
// 关键接口：
// bool insert(ll x)   -> 返回 true 表示秩增加（只有这种才需要传播）
// bool canRepresent(ll x)
// ll   maxXor() / minXor() / kthXor(k)
```

**本题特有的实现要点**：
- `common`：公共线性基。
- `local[i]`：第 `i` 个集合的局部基。
- `span[i]`：显式保存的 `U_i` 元素（当 `|U_i| <= 2|S_i|` 时）。
- `events`：待传播的独立向量队列。
- `active`：仍需显式维护的集合。
- 枚举空间用 `W' = W ∪ {w ⊕ x | w ∈ W}`（空间翻倍）。

**复杂度**：`O(mC + m²n + 2^m)`。

**同类题**：P3812【模板】线性基、P3857 [TJOI2008] 彩灯、CF 1100F Ivan and Burgers。

## 2. B. Bread —— 凸多边形最远点 + 半圆上包络

**题目要求**：凸多边形沿直线滚动，求 `lim S(k)/L(k)`。

**算法点**：

1. **周期性**：滚一圈 = 平移周长 `P`，所以极限 = `S(一个周期) / P`。
2. **顶点轨迹是圆**：绕支点 `i` 旋转时，顶点 `j` 的轨迹是圆心 `(c_i, 0)`、半径 `|A_iA_j|` 的圆。
3. **每个支点只需最远点**：`r_i = max_j |A_iA_j|`。**这就是"凸多边形最远点"问题**。
4. **决策单调分治**：把问题拆成"后缀最远点"和"前缀最远点"，各自用分治求（见 [20-§5](20-计算几何.md)）。
5. **上边界 = 半圆上包络**，所有圆共享 `-x²`，等价于**直线** `2c·x + (r²-c²)` 的上包络。
6. **单调栈维护包络**：`c` 递增 ⇒ 斜率递增（见 [20-§6](20-计算几何.md)）。
7. **积分**：`∫sqrt(r²-x²)dx`（见 [20-§7](20-计算几何.md)）。

**核心模板**：

```cpp
// (1) 决策单调分治求最远点
//     solve(l, r, optL, optR, suffix)
// (2) 单调栈求直线包络
//     UpperEnvelope::add(k, b) / query(x)
// (3) 圆弧积分
//     primitive(x, r) = (x*sqrt(r²-x²) + r²*asin(x/r)) / 2
// (4) 半径平方比较，避免开根
```

**易错点**：
- 只保留当前周期的圆会缺两端 → 保留 `shift ∈ {-1, 0, 1}` 三个周期。
- 距离比较用整数平方。
- `sqrt` / `asin` 参数要截断。
- **不要**对所有点直接套旋转卡壳的单调假设（前缀/后缀要分开）。

## 3. C. Cut Tree —— 分块 + 双并查集

**题目要求**：树边按编号，`q` 次询问"只保留 `[l,r]` 中除 `f` 外的边，最大连通块权值"。

**算法点**：

1. **分块**：把边编号分块，每块内询问按 `r` 升序处理。
2. **公共并查集**：维护 `[R+1, r]` 的边，跨询问保留（只增不减）。
3. **临时并查集**：每次询问补入 `[l, R]` 至多 `B` 条边，用 `epoch/stamp` 惰性清空。
4. **删边 `f` 的处理**：
   - `f <= R`：在临时补边时跳过。
   - `f > R`：用 DFS 序 + 树状数组计算"被切开的公共块"两侧权值。
5. **树状数组存 `tin[top(块)]` 位置**的块权值（见 [06](06-树状数组.md)、[24-§1](24-分块与莫队.md)）。
6. **惰性最大值堆**：公共块最大值用堆，删除时逻辑弹出。

**核心模板**：

```cpp
// (1) DFS 序：tin/tout，子树 = 连续区间
// (2) 树状数组：单点加 + 前缀和（存 tin[top] 处）
// (3) 可撤销/临时并查集：epoch 标记惰性初始化
// (4) 惰性堆：(value, id)，弹出时校验 id 是否仍有效
```

**复杂度**：`O(n²/B·log n + qB·α(n) + q log q)`，块长取 `~2.2n/√q`。

**同类思想题**：P4117 [Ynoi2018] 五彩斑斓的世界（分块）、P3203 弹飞绵羊（分块）。

## 4. E. Exponent —— 单位群结构与阶

**题目要求**：`Σ_{a=1}^{n} ord_n(a)`，`n <= 1e9`，不取模。

**算法点**：

1. `gcd(a,n) > 1` 的阶为 0，只看单位群。
2. **CRT 拆直积**（见 [03](03-中国剩余定理与模线性方程.md)）。
3. **素数幂单位群结构**（见 [28-§3](28-数论进阶-筛法与分解.md)）：
   - 奇素数幂 `p^e` → 循环群 `C_{p^(e-1)(p-1)}`
   - `2^1` 平凡，`2^2` → `C₂`，`2^e (e>=3)` → `C₂ × C_{2^(e-2)}`
4. **按素数归类**：`G_q = C_{q^{a_1}} × ... × C_{q^{a_t}}`。
5. **`F(k) = q^{Σ min(a_j,k)}`**，阶恰为 `q^k` 的元素数 = `F(k) - F(k-1)`。
6. `W_q = 1 + Σ q^k (F(k)-F(k-1))`，答案 `= Π_q W_q`。

**核心模板**：

```cpp
// (1) 试除分解（n <= 1e9，筛到 31623）
// (2) 增量计算 F(k)：F(k)/F(k-1) = q^{#{j: a_j >= k}}
// (3) 不取模，用 long long（答案 <= n·φ(n) <= 1e18）
```

**易错点**：`2^e` 不能当普通奇素数幂；`previous` 每层要更新；`n=1` 空乘积为 1。

## 5. F. Folding Game —— 左偏树 + 直径折叠

**题目要求**：每次沿直径对称折叠，求最多折叠次数。

**算法点**：

1. **策略无关**：折叠次数与选择哪条直径无关（题解结论，直接用）。
2. **固定端点**：固定一个直径端点 `root`，每次从 `root` 出发找最长路即当前直径。
3. **子树高度堆**：每个点 `u` 维护"孩子高度"的**大根堆**，堆顶就是最长路方向。
4. **左偏树**：支持合并孩子堆、弹出堆顶（见 [22-§3](22-高级数据结构-主席树与树套树.md)）。
5. **折叠模拟**：
   - 沿堆顶弹出整条直径 `path`；
   - 对称位置 `path[i]` 与 `path[D-i]` 合并堆；
   - 从中间往根重建高度，把 `path[i]` 加回 `path[i-1]` 的堆。

**核心模板**：

```cpp
// LeftistHeap:
//   int merge(int a, int b)   // 合并，O(log n)
//   int pop(int a)            // 弹出根，O(log n)
//   int top(int a)
```

**易错点**：
- `head[u]`（孩子堆）与"`u` 作为堆节点"是两个角色。
- 必须先弹出直径边，再合并旁支。
- 必须在加回父亲堆**之前**更新高度。

**同类题**：P3377【模板】左偏树、P2713 罗马游戏、P1552 [APIO2012] 派遣。

## 6. H. Hidden Track —— 交互 + 按位构造

**题目要求**：交互还原隐藏排列（路径），每次询问"某点集的割边数 mod 3"。

**算法点**：

1. **按位查询**：对每一位 `b`，查询"第 `b` 位为 1 的顶点集"的割边数。
2. **翻转单点**：得到 `Δ_v = d_v - 2t_v (mod 3)`（`d_v` 是度数，`t_v` 是邻居中该位为 1 的数量）。
3. **省一次查询**：`Σ_v Δ_v ≡ 2(n-1) - c (mod 3)`，最后一个顶点的 `Δ` 直接算出来。
4. **区分端点/内部点**：端点 `Δ != 0`；内部点存在某位使 `Δ = 0`。
5. **逐位恢复后继**：`count ≡ (d ∓ deg) (mod 3)`，减去前驱贡献即得后继该位。
6. **交互细节**：每次输出后 `fflush` / `endl`；读到 `-1` 立即退出。

**核心模板**：

```cpp
// 查询数恰好 n·ceil(log2 n)
// 关键公式：
//   delta[v][b] = mod3(ask(mask, v) - base)
//   delta[n-1][b] = mod3(2*(n-1) - base - sum_{v<n-1} delta[v][b])
```

**同类题**：CF 系列交互题、P1733 猜数（交互框架）。

## 7. I. Island —— 树上状态压缩 DP

**题目要求**：有序树 + 相邻叶子连边，每条边 `1/2` 概率保留，求连通块数期望（模 998244353）。

**算法点**：

1. **边界只有 3 个点**：`u`（连父亲）、`L`（子树第一片叶子）、`R`（最后一片叶子）。
2. **5 种状态**：三点集合划分只有 5 种（`000, 001, 010, 011, 012`）。
3. **`dp[u][s]`**：边界状态 `s` 的概率；**`expectation[u]`**：无条件期望连通块数。
4. **合并孩子**：两图之间最多两条新边（父子边 + 叶子链边），枚举 4 种保留方案，用**并查集**判断"是否真的合并"。
5. **预计算表**：`ways[a][b][s]`（状态组合数）、`reductions[a][b]`（成功合并次数）。
6. **期望公式**：`E_new = E_old + E_child - E[成功合并次数]`。

**核心模板**：

```cpp
// (1) 6 点并查集（左图 0/1/2，右图 3/4/5）
// (2) 预计算 ways[a][b][s] 与 reductions[a][b]
// (3) 逆序遍历 order（父亲先于孩子），避免递归爆栈
// (4) 模意义下的 INV2 / INV4
```

**易错点**：
- 第一个孩子只有 1 条新边，后续孩子有 2 条，转移不同。
- 成环的边**不减少**连通块数。
- 别漏叶子链边。

**同类题**：P3267 [JLOI2016] 侦察守卫（树上状压）、CF 1097G Vladislav and a Great Legend。
