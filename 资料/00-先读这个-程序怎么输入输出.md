# 00 先读这个：程序怎么读入、怎么输出

> 这份资料里的每个算法，都配了**能直接跑的程序**和**样例输入/输出**（在 `示例/` 目录）。
> 本节先讲清最基本的事情：一个比赛程序到底是怎么工作的。

---

## 1. 比赛程序长什么样

一个 ICPC 题目的程序，永远是这个结构：

```cpp skip
#include <bits/stdc++.h>
using namespace std;

int main() {
    // 第 1 步：读入数据（从"标准输入"读）
    int n;
    cin >> n;

    // 第 2 步：算
    int ans = n * 2;

    // 第 3 步：输出答案（往"标准输出"写）
    cout << ans << '\n';
    return 0;
}
```

- **标准输入（stdin）**：程序"读"的地方。评测机把题目的数据塞进这里。
- **标准输出（stdout）**：程序"写"的地方。评测机从这里读你的答案，和标准答案比对。
- 你**不需要**打开文件、不需要写路径、不需要管输入从哪来。`cin`/`scanf` 就是从 stdin 读，`cout`/`printf` 就是往 stdout 写。

## 2. 一道题从"题面"到"程序"的对应关系

题面里通常这么写：

```
输入格式
第一行一个整数 n（1 ≤ n ≤ 100）。
第二行 n 个整数 a1, a2, ..., an。

输出格式
输出这些数的和。

样例输入
5
1 2 3 4 5

样例输出
15
```

对应的程序就是：

```cpp skip
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;                     // 读第一行的 n
    long long sum = 0;
    for (int i = 0; i < n; ++i) {
        int x;
        cin >> x;                 // 循环读第二行的 n 个数
        sum += x;
    }
    cout << sum << '\n';          // 输出
    return 0;
}
```

把「样例输入」那 6 行粘进程序运行时的输入，程序就会打出 `15`。

## 3. 怎么在电脑上跑起来

### 3.1 编译

```bash
g++ -std=c++17 -O2 a.cpp -o a
```

### 3.2 运行 + 手动输入

```bash
./a          # Linux / Mac
a.exe        # Windows
```

然后**手动敲**样例输入，每行回车，最后按 `Ctrl+Z`（Windows）或 `Ctrl+D`（Linux）表示输入结束。

> ⚠️ 如果你忘了输入结束符，程序会一直等，看起来像"卡住了"。

### 3.3 用文件重定向（推荐）

```bash
./a < sample.in > my.out        # 从 sample.in 读，结果写到 my.out
```

这样不用手敲，改数据也方便。

### 3.4 本资料 `示例/` 目录的约定

| 文件 | 含义 |
|---|---|
| `xx_名字.cpp` | 可直接编译运行的完整程序 |
| `xx_名字.in` | 样例输入（就是该程序的 stdin） |
| `xx_名字.out` | 样例输出（程序应该打出的内容） |

一键验证（PowerShell）：

```powershell
g++ -std=c++17 -O2 01_快读.cpp -o t.exe
Get-Content 01_快读.in | .\t.exe      # 屏幕上打出来的应该和 .out 文件一样
```

## 4. 常见的输入输出"花样"

### 4.1 多组数据（`T` 组）

题面会说"第一行一个整数 `T`，表示测试用例组数"：

```cpp skip
int T;
cin >> T;
while (T--) {
    int n;
    cin >> n;
    // 处理这一组
}
```

### 4.2 读到文件结束（没有 T）

题面会说"多组数据，读到文件末尾"：

```cpp skip
int n;
while (cin >> n) {        // 读不到就退出循环
    // 处理
}
```

用 `scanf` 的写法：`while (scanf("%d", &n) != EOF)`。

### 4.3 字符串

```cpp skip
string s;
cin >> s;                 // 读一个"不含空格"的单词
getline(cin, s);          // 读一整行（含空格）
```

**坑**：`cin >> n` 之后如果接 `getline`，会读到那个残留的换行符，要先 `cin.ignore()`。

### 4.4 输出多个数

```cpp skip
cout << a << ' ' << b << '\n';          // 空格分隔，最后换行
// 或者
printf("%d %d\n", a, b);
```

### 4.5 输出浮点数

```cpp skip
printf("%.6f\n", ans);                  // 保留 6 位小数
cout << fixed << setprecision(6) << ans << '\n';
```

### 4.6 输出 `long long`

```cpp skip
long long x;
printf("%lld\n", x);                    // 注意是 %lld
cout << x << '\n';
```

## 5. 本资料里"模板"的用法

资料里的算法大多写成 `struct`，比如并查集：

```cpp skip
DSU dsu(n);            // 建一个 n 个点的并查集
dsu.unite(1, 2);       // 合并 1 和 2
bool same = dsu.same(1, 2);
```

**用法三步**：

1. 把 `struct` 整段复制到你的程序里（或保存成 `template.cpp` 后在需要时粘贴）。
2. 在 `main()` 里按注释创建对象、调用函数。
3. 看 `示例/` 里的同名 `.cpp`，那就是"怎么调用"的完整示范。

**每个 `示例/*.cpp` 的注释里都写了**：
- 这个算法**解决什么问题**
- 输入是什么格式
- 输出是什么格式

## 6. 常见"我也不知道为什么错了"

| 现象 | 原因 |
|---|---|
| 程序一直不动 | 忘了输入结束符（`Ctrl+Z` / `Ctrl+D`） |
| 输出一大堆乱码 | 没初始化变量 / 数组越界 |
| 样例过了但 WA | 没考虑 `n = 1`、全相同、负数、`long long` 溢出 |
| 输出格式不对 | 少换行、多空格、`YES` 写成 `Yes` |
| 多组数据全错 | 忘了每组重置数组/变量 |

---

## 7. 建议的练习顺序

1. 先跑 `示例/01_快读.cpp`，理解"输入 → 计算 → 输出"。
2. 再跑 `示例/05_并查集.cpp`，理解"struct + 调用"。
3. 之后按 `资料/README.md` 的目录，遇到哪个算法就去看对应示例。

**核心心法**：所有算法题都是「**读入 → 建数据结构 → 调方法 → 输出**」。会套这一个模板，就够用了。
