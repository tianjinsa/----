# 16 二分与三分

> 二分 = 在单调性上找边界；三分 = 在单峰函数上找极值。这两种方法**直观、好写**，不配例题，只给模板和坑。

---

## 1. 整数二分（只背两种）

```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;

// A：最小的 x 使 check(x) 为真（false...false | true...true）
template <class F>
ll first_true(ll lo, ll hi, F check) {
    ll ans = hi + 1;
    while (lo <= hi) {
        ll mid = lo + (hi - lo) / 2;
        if (check(mid)) { ans = mid; hi = mid - 1; }
        else lo = mid + 1;
    }
    return ans;
}

// B：最大的 x 使 check(x) 为真（true...true | false...false）
template <class F>
ll last_true(ll lo, ll hi, F check) {
    ll ans = lo - 1;
    while (lo <= hi) {
        ll mid = lo + (hi - lo) / 2;
        if (check(mid)) { ans = mid; lo = mid + 1; }
        else hi = mid - 1;
    }
    return ans;
}
```

**三种等价写法**（知道即可，用上面的模板就行）：

```cpp
// 1) 闭区间 [lo, hi]，ans 记录
// 2) 左闭右开 [lo, hi)，while (lo < hi)
int lower_bound_pos(const vector<int> &a, int x) {
    int lo = 0, hi = (int)a.size();
    while (lo < hi) {
        int mid = lo + (hi - lo) / 2;
        if (a[mid] >= x) hi = mid; else lo = mid + 1;
    }
    return lo;
}
// 3) STL：lower_bound / upper_bound / equal_range
```

## 2. 实数二分

```cpp
#include <bits/stdc++.h>
using namespace std;
using ld = long double;

// 固定迭代次数最稳（100 次足够），避免 eps 死循环
template <class F>
ld binary_real(ld lo, ld hi, F check) {     // 找满足 check 的最小 x
    for (int it = 0; it < 100; ++it) {
        ld mid = (lo + hi) / 2;
        if (check(mid)) hi = mid; else lo = mid;
    }
    return hi;
}
```

## 3. 三分（单峰/单谷）

```cpp
#include <bits/stdc++.h>
using namespace std;
using ld = long double;

template <class F>
ld ternary_max(ld lo, ld hi, F f) {          // 先增后减
    for (int it = 0; it < 200; ++it) {
        ld m1 = lo + (hi - lo) / 3;
        ld m2 = hi - (hi - lo) / 3;
        if (f(m1) < f(m2)) lo = m1; else hi = m2;
    }
    return f((lo + hi) / 2);
}

template <class F>
ld ternary_min(ld lo, ld hi, F f) {          // 先减后增
    for (int it = 0; it < 200; ++it) {
        ld m1 = lo + (hi - lo) / 3;
        ld m2 = hi - (hi - lo) / 3;
        if (f(m1) > f(m2)) lo = m1; else hi = m2;
    }
    return f((lo + hi) / 2);
}
```

**三分失效**：函数不单峰（多个局部极值）→ 上模拟退火；函数有"平底"→ 用整数三分或直接对导数二分。

## 4. 二分答案的 check 怎么写（这部分才需要经验）

| 题目关键词 | check 的做法 |
|---|---|
| "最小化最大值" / "最大化最小值" | 贪心扫描 / 并查集 / 二分图判定 |
| "第 k 小" | 数位 DP / 组合计数 |
| "最大平均值" | 每个元素减 `mid`，求最大子段和是否 `>= 0` |
| "最长可行" | 双指针 / 单调队列 |
| "最少代价" | 最短路 / 最小割 |
| "能否连通" | 并查集 / BFS |
| "能否放得下" | 贪心装箱 |

**二分答案的固定骨架**：

```cpp
// ll lo = 下界, hi = 上界;
// while (lo < hi) { mid = (lo+hi)/2; if (check(mid)) hi = mid; else lo = mid+1; }
// 输出 lo（最小可行解）
```

**常见上/下界**：

| 场景 | lo | hi |
|---|---|---|
| 数组分段 / 砍树 | `max(a[i])` | `sum(a)` |
| 最大边权 | `0` | `max(w)` |
| 距离 | `0` | `1e18` |
| 时间 | `0` | `1e9` |
| 计数 | `0` | `n` |

---

## 5. 坑

1. `mid = (lo + hi) / 2` 在 `lo, hi` 接近 `2^62` 时溢出 → 用 `lo + (hi - lo) / 2`。
2. `while (lo <= hi)` 与 `while (lo < hi)` 别混用；`lo/hi` 的更新必须配套。
3. `check` 里的累加用 `ll`，别用 `int`。
4. 浮点二分**固定迭代次数**，别用 `while (hi - lo > eps)`。
5. 二分出答案后需要**构造方案**时，再跑一遍 `check(ans)` 顺便记录。
