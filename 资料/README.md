> 使用方式：比赛时按「标签页 → 搜索关键词」查，**不要试图背全部**。
> 结构：每个算法都写了「**用途 → 思路 → 模板 → 实例/例题**」，文件末尾有「思路与例题索引」表。

## 比赛使用建议

1. **开局贴**：[01](01-基础模板与卡常.md) 的万能头 + 快读 + `__int128` 输出。
2. **按题查表**：用上面的"按题目类型"表格定位。
3. **不要背**：把本资料当"可搜索的字典"，比赛时开两个窗口对照抄。
4. **抄完改三处**：数组大小、`1-based` 还是 `0-based`、取模的地方。
5. **对拍**：见 [21-§7](21-杂项技巧与对拍调试.md)。
