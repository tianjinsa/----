# 30 DP 优化

> **用途**：把 `O(n^2)` 的 DP 压到 `O(n)` 或 `O(n log n)`。判断标准是**转移式的形状**。

| 转移式形状 | 优化方法 |
|---|---|
| `f[i] = min_j { f[j] + w(j) }`（`w` 与 i 无关） | 前缀 min |
| `f[i] = min_{j in 窗口} { f[j] } + c(i)` | **单调队列** |
| `f[i] = min_j { f[j] + a[i]*b[j] }`（乘积项） | **斜率优化 / 凸包** |
| `opt[i]` 单调不降 | **决策单调性分治** |
| `f[i][j]` 合并两个区间 | 四边形不等式 |
| 多重背包 | 单调队列 / 二进制拆分 |
| 树形背包 | 按 `sz` 合并 |

---

## 1. 单调队列优化（滑动窗口最值）

**用途**：转移依赖"前 `k` 个状态的最值"。

**实例：P1886 滑动窗口 / P1440 求m区间内的最小值**

```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;

// 例：f[i] = min_{i-k <= j < i} f[j] + a[i]
vector<ll> dp_sliding_window(const vector<ll> &a, int k) {
    int n = (int)a.size();
    vector<ll> f(n, 0);
    deque<int> dq;                        // 存下标，f 值单调递增
    for (int i = 0; i < n; ++i) {
        while (!dq.empty() && dq.front() < i - k) dq.pop_front();
        if (i > 0) f[i] = f[dq.front()] + a[i];
        while (!dq.empty() && f[dq.back()] >= f[i]) dq.pop_back();
        dq.push_back(i);
    }
    return f;
}
```

**实例：P1020 / P1725 琪露诺** —— `f[i] = max_{i-R <= j <= i-L} f[j] + a[i]`。

**实例：多重背包的单调队列优化**（P1776 的 `O(nV)` 版）：

```cpp
#include <bits/stdc++.h>
using namespace std;

// 多重背包：物品 (w, v, c)，容量 V
// f[j] = max(f[j], f[j-k*w] + k*v) for k <= c
// 按 j mod w 分组，单调队列维护
int multi_knapsack_mono(int V, const vector<array<int,3>> &items) {
    vector<int> f(V + 1, 0);
    for (auto [w, v, c] : items) {
        if (w == 0) { if (v > 0) for (int &x : f) x += c * v; continue; }
        vector<int> g(f);
        for (int r = 0; r < w; ++r) {
            deque<int> dq;
            for (int j = r, t = 0; j <= V; j += w, ++t) {
                // 候选：g[j] - t*v，窗口 [t-c, t]
                while (!dq.empty() && dq.front() < t - c) dq.pop_front();
                // 注意：这里用 g 的对应位置
                if (!dq.empty()) f[j] = max(f[j], g[dq.front() * w + r] + (t - dq.front()) * v);
                int cur = g[j] - t * v;
                while (!dq.empty()
                       && g[dq.back() * w + r] - dq.back() * v <= cur) dq.pop_back();
                dq.push_back(t);
            }
        }
    }
    return f[V];
}
```

## 2. 斜率优化（凸包优化）

**用途**：转移式形如
`f[i] = min_j { f[j] + a[i] * x[j] + b[j] } + c[i]`，
其中 `a[i]` 单调、`x[j]` 单调。

**思路**：把 `j` 看成一个点 `(x[j], f[j] + b[j])`，求"斜率 `-a[i]` 的直线过某点时的最小截距"。
用**单调队列维护下凸壳**，`O(n)`。

```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;
using ld = long double;

// 斜率优化通用骨架：f[i] = min_j { f[j] + a[i]*x[j] + y[j] }
// 要求：a[i] 单调递增（或递减），x[j] 单调递增
struct SlopeOptimization {
    struct P { ll x, y; };
    vector<P> hull;
    int head = 0;

    // 叉积 (b-a) × (c-a) > 0 表示左转
    static ll cross(const P &a, const P &b, const P &c) {
        return (b.x - a.x) * (c.y - a.y) - (b.y - a.y) * (c.x - a.x);
    }
    void add(ll x, ll y) {                 // 加入点 (x, y)
        P p{x, y};
        while (hull.size() >= 2 &&
               cross(hull[hull.size() - 2], hull.back(), p) <= 0) hull.pop_back();
        hull.push_back(p);
    }
    // 查询斜率 k 下的最小 f[j] + k*x[j]（k 单调递增时用指针，O(1) 均摊）
    ll query(ll k) {
        while (head + 1 < (int)hull.size() &&
               hull[head + 1].y - hull[head].y <= k * (hull[head + 1].x - hull[head].x)) ++head;
        return hull[head].y - k * hull[head].x;
    }
};
```

> **符号容易搞反**：`f[i] = min (f[j] + a[i]*x[j] + y[j])` 等价于
> `f[i] = min (y[j] + a[i]*x[j])`，即查询"斜率 `-a[i]` 时 `y[j] - (-a[i])*x[j]` 的最小值"。
> **建议**：先写朴素 `O(n^2)`，再用小数据对拍斜率优化版。

**实例**：P3628 [APIO2010] 特别行动队、P2120 [ZJOI2007] 仓库建设、P3195 [HNOI2008] 玩具装箱。

**玩具装箱的转移式**：

```
f[i] = min_j { f[j] + (S[i] - S[j] + i - j - 1 - L)^2 }
```

展开后是 `f[j] + t[j]^2 - 2*t[i]*t[j] + t[i]^2`，属于标准斜率优化。

## 3. 决策单调性分治

**用途**：`f[i] = min_j { g[j] + w(j, i) }`，且**最优决策点 `opt[i]` 单调不降**（满足四边形不等式）。

```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;

// 决策单调性分治：solve(l, r, optL, optR)
// f[i] = min_{j in [optL, optR]} g[j] + w(j, i)
template <class W>
void solve_dc(int l, int r, int optL, int optR,
              vector<ll> &f, const vector<ll> &g, W w) {
    if (l > r) return;
    int mid = (l + r) >> 1;
    int best = optL;
    ll bestVal = LLONG_MAX / 4;
    for (int j = max(optL, 0); j <= min(optR, mid); ++j) {
        ll v = g[j] + w(j, mid);
        if (v < bestVal) { bestVal = v; best = j; }
    }
    f[mid] = bestVal;
    solve_dc(l, mid - 1, optL, best, f, g, w);
    solve_dc(mid + 1, r, best, optR, f, g, w);
}
```

**实例**：CF 868F Yet Another Minimization Problem、P3515 [POI2011] Lightning Conductor。

**怎么判断能不能用**：
1. 写出 `w(j, i)`。
2. 检查是否满足**四边形不等式**：`w(a,c) + w(b,d) <= w(a,d) + w(b,c)`（`a<=b<=c<=d`）。
3. 或**打表观察 `opt[i]` 是否单调**（最实用）。

## 4. 四边形不等式优化（区间 DP）

**用途**：区间 DP `f[l][r] = min_k { f[l][k] + f[k+1][r] } + w(l, r)`，若 `w` 满足四边形不等式，则 `opt[l][r]` 满足单调性，可以 `O(n^2)`。

```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;

// 石子合并的 O(n^2) 四边形不等式优化
ll stone_merge_quadrangle(const vector<ll> &a) {      // a 下标 1..n
    int n = (int)a.size() - 1;
    vector<ll> pre(n + 1, 0);
    for (int i = 1; i <= n; ++i) pre[i] = pre[i - 1] + a[i];
    vector<vector<ll>> f(n + 2, vector<ll>(n + 2, 0));
    vector<vector<int>> opt(n + 2, vector<int>(n + 2, 0));
    for (int i = 1; i <= n; ++i) opt[i][i] = i;
    for (int len = 2; len <= n; ++len)
        for (int l = 1; l + len - 1 <= n; ++l) {
            int r = l + len - 1;
            f[l][r] = LLONG_MAX / 4;
            for (int k = opt[l][r - 1]; k <= opt[l + 1][r]; ++k) {
                ll v = f[l][k] + f[k + 1][r] + pre[r] - pre[l - 1];
                if (v < f[l][r]) { f[l][r] = v; opt[l][r] = k; }
            }
        }
    return f[1][n];
}
```

> **注意**：`opt[l][r]` 的枚举范围是 `[opt[l][r-1], opt[l+1][r]]`，这是四边形不等式的结论。
> **代价**：只适用于 `w` 满足四边形不等式的情形（区间和、区间长度等）。

### 5.2 前缀和 / 差分优化

`f[i] = Σ_{j} f[j]` 型转移 → 前缀和 `O(1)`。

### 5.3 矩阵快速幂优化线性递推

`O(k^3 log n)`；若递推阶数小（`k <= 5`），矩阵最方便。

### 5.4 滚动数组

`f[i][j]` 只依赖 `f[i-1][*]` → 压成两行。

## 6. 选型速查

| 转移式 | 优化 |
|---|---|
| `f[i] = min(f[j]) + c`，`j` 在窗口内 | 单调队列 |
| `f[i] = min(f[j] + a[i]·x[j] + y[j])` | 斜率优化 |
| `opt[i]` 单调 | 决策单调性分治 |
| 区间 DP + 四边形不等式 | `O(n^2)` 枚举 `opt` |
| 多重背包 | 单调队列 |
| 线性递推、`n` 大 | 矩阵快速幂 / BM |
| 树形背包 | 按 `sz` 合并 |

**通用建议**：
1. **先写朴素版**，用 `n <= 100` 对拍。
2. 斜率优化最容易写错符号，**一定对拍**。
3. 决策单调性要**验证 `opt` 单调**（打表）。
4. 单调队列注意**队首过期**的判定 `dq.front() < i - k`。


### 怎么用（照抄这段 `main`，只改【输入】【输出】两处）

上面是模板本体。实际写题时：**把上面的 struct 整段粘过来 → 再粘这段 `main` → 只改标了【输入】【输出】的行**。

```cpp skip
#include <bits/stdc++.h>
using namespace std;
using ll = long long;

// ===== 粘贴点：把上面的 dp_sliding_window 粘到这里 =====

int main() {
    // ===================== 【输入】改这里 =====================
    int n, k;
    scanf("%d %d", &n, &k);               // 数组长度、窗口大小
    vector<ll> a(n);
    for (int i = 0; i < n; ++i) scanf("%lld", &a[i]);
    // ========================================================

    // ===================== 【核心】算法流程 =====================
    // 单调队列优化：转移依赖"前 k 个状态的最值"
    //   维护一个双端队列，里面存下标，对应 f 值单调
    //   1) 队首过期（下标 < i-k）就弹出
    //   2) 用队首更新 f[i]
    //   3) 队尾比 f[i] 大的都弹掉，再压入 i
    // 每个元素最多进出各一次，所以是 O(n)
    vector<ll> f = dp_sliding_window(a, k);
    // ========================================================

    // ===================== 【输出】改这里 =====================
    printf("%lld\n", f[n - 1]);
    // ========================================================
    return 0;
}
```

**斜率优化 / 决策单调 / 四边形不等式** 的核心调用：

## 7. 思路与例题索引

| 算法 | 思路一句话 | 用途 | 例题 |
|---|---|---|---|
| 单调队列 | 维护窗口内最优，队首过期弹出 | 窗口最值转移 | P1886、P1725 琪露诺 |
| 多重背包（单调队列） | 按 `j mod w` 分组 | `O(nV)` 多重背包 | P1776 宝物筛选 |
| 斜率优化 | 点 `(x[j], f[j]+b[j])` 维护下凸壳 | `f[i] = min f[j] + a[i]x[j] + y[j]` | P3628 特别行动队、P3195 玩具装箱 |
| 决策单调性分治 | `opt` 单调，分治求 | 费用与区间相关 | CF 868F、P3515 Lightning Conductor |
| 四边形不等式 | `opt[l][r] ∈ [opt[l][r-1], opt[l+1][r]]` | 区间 DP | P1880 石子合并（O(n^2) 版） |
| 树上背包合并 | 按 `sz` 限制枚举 | 树形背包 | P2014 选课、P1273 |
| 矩阵快速幂 | 线性递推 → 矩阵幂 | `n` 大的递推 | P1939【模板】矩阵加速 |

**判断顺序**：窗口 → 单调队列；乘积项 → 斜率；`opt` 单调 → 分治。
