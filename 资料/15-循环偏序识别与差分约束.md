# 15 循环偏序识别与差分约束

> 你点名的内容。**"循环偏序"= 偏序关系上出现环 ⇒ 关系不一致/无解**。
> 本篇给全：拓扑排序判环、Tarjan 判环、差分约束（判断"循环不等式"是否有解）、带权并查集判一致性、以及竞赛里"关系自相矛盾"的几种常见模型。

---

## 1. 什么是"循环偏序"

偏序要求**传递性 + 反对称性**。如果给出的关系里出现

```
a < b,  b < c,  c < a        ⇒ 环 ⇒ 不是偏序（关系矛盾）
```

对应的算法问题：

| 题目表述 | 判定手段 |
|---|---|
| "是否存在合法的排列顺序" | 拓扑排序判环 |
| "给定的不等关系是否矛盾" | 差分约束 / 带权并查集 |
| "x1 < x2, x2 < x3, ..., 问是否有解" | 差分约束（SPFA 判负环） |
| "a 与 b 同类，b 与 c 不同类，... 是否可能" | 种类并查集 / 带权并查集 |
| "区间和方程 sum[l..r] = x，问是否一致" | 带权并查集 / 差分约束 |
| "2-SAT 有无解" | Tarjan SCC（见 12 号文件） |
| "偏序集是否成环" | 传递闭包后查 `d[i][i]` |

## 2. 拓扑排序判环（最常用）

```cpp
#include <bits/stdc++.h>
using namespace std;

// 返回 true 表示有环（不是偏序）；顺带给出一个拓扑序
struct TopoSort {
    int n;
    vector<vector<int>> g;
    vector<int> indeg;
    explicit TopoSort(int n_) : n(n_), g(n_ + 1), indeg(n_ + 1, 0) {}
    void addEdge(int u, int v) { g[u].push_back(v); ++indeg[v]; }   // u -> v

    // 返回 {是否有环, 拓扑序}
    pair<bool, vector<int>> run() {
        queue<int> q;
        for (int i = 1; i <= n; ++i) if (!indeg[i]) q.push(i);
        vector<int> ord;
        while (!q.empty()) {
            int u = q.front(); q.pop();
            ord.push_back(u);
            for (int v : g[u]) if (--indeg[v] == 0) q.push(v);
        }
        return {(int)ord.size() != n, ord};
    }
};
```

**注意**：`run()` 会破坏 `indeg`，多测需要重建或用副本。

### 2.2 求字典序最小的拓扑序 + 编号反着来（经典技巧）

**问题**：给每个点赋 `1..n` 的排名，要求 `u < v` 时 `pos[u] < pos[v]`，且**编号小的尽量靠前**。
做法：建**反图**，用大根堆做拓扑，从 `n` 倒着填。

```cpp
#include <bits/stdc++.h>
using namespace std;

// 反图 + 大根堆：编号小的尽量靠前
vector<int> topo_min_label(int n, const vector<vector<int>> &rg, vector<int> indeg) {
    priority_queue<int> pq;
    for (int i = 1; i <= n; ++i) if (!indeg[i]) pq.push(i);
    vector<int> pos(n + 1);
    for (int t = n; t >= 1; --t) {
        if (pq.empty()) return {};             // 有环
        int u = pq.top(); pq.pop();
        pos[u] = t;
        for (int v : rg[u]) if (--indeg[v] == 0) pq.push(v);
    }
    return pos;
}
```

### 2.3 拓扑排序 + DP（DAG 上的最长路、方案数、可达性）

```cpp
#include <bits/stdc++.h>
using namespace std;

// DAG 最长路 + 方案数
struct DAGPath {
    int n;
    vector<vector<int>> g;
    vector<int> indeg;
    explicit DAGPath(int n_) : n(n_), g(n_ + 1), indeg(n_ + 1, 0) {}
    void addEdge(int u, int v) { g[u].push_back(v); ++indeg[v]; }

    // 返回 {最长路长度, 方案数}；有环返回 {-1, 0}
    pair<int, long long> longest(int src, long long MOD = 1000000007) {
        vector<int> d(n + 1, -1);
        vector<long long> cnt(n + 1, 0);
        auto ind = indeg;
        queue<int> q;
        for (int i = 1; i <= n; ++i) if (!ind[i]) q.push(i);
        d[src] = 0; cnt[src] = 1;
        int seen = 0;
        while (!q.empty()) {
            int u = q.front(); q.pop(); ++seen;
            for (int v : g[u]) {
                if (d[u] >= 0) {
                    if (d[u] + 1 > d[v]) { d[v] = d[u] + 1; cnt[v] = cnt[u]; }
                    else if (d[u] + 1 == d[v]) cnt[v] = (cnt[v] + cnt[u]) % MOD;
                }
                if (--ind[v] == 0) q.push(v);
            }
        }
        if (seen != n) return {-1, 0};
        int best = -1;
        long long ways = 0;
        for (int i = 1; i <= n; ++i) {
            if (d[i] > best) { best = d[i]; ways = cnt[i]; }
            else if (d[i] == best) ways = (ways + cnt[i]) % MOD;
        }
        return {best, ways};
    }
};
```

## 3. 差分约束（判断不等式组是否有解）★

**形式**：一堆形如 `x_v - x_u <= w` 的不等式。

**建图**：连边 `u -> v` 权值 `w`，**跑最短路**。
- 有**负环** ⇒ 无解（矛盾）。
- `dist[v]` 就是 `x_v` 的一组可行解（相对 `x_u = 0`）。

| 不等式 | 连边 |
|---|---|
| `x_v - x_u <= w` | `u -> v`，权 `w` |
| `x_v - x_u >= w` | `v -> u`，权 `-w` |
| `x_v - x_u < w` | `u -> v`，权 `w-1`（整数） |
| `x_v - x_u == w` | `u->v` 权 `w` **且** `v->u` 权 `-w` |
| `x_u <= x_v` | `v -> u`，权 `0` |

```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;
constexpr ll LINF = 0x3f3f3f3f3f3f3f3fLL;

// 差分约束：判断可行性 + 求一组解
// 返回 {是否有解, 一组解}；无解时第二项为空
struct DifferenceConstraints {
    struct Edge { int to; ll w; };
    int n;
    vector<vector<Edge>> g;
    explicit DifferenceConstraints(int n_) : n(n_), g(n_ + 1) {}
    void addLE(int u, int v, ll w) { g[u].push_back({v, w}); }        // x_v - x_u <= w
    void addGE(int u, int v, ll w) { g[v].push_back({u, -w}); }       // x_v - x_u >= w
    void addEQ(int u, int v, ll w) { addLE(u, v, w); addGE(u, v, w); }

    // 用 SPFA 判负环（所有点入队，等价于加超级源点）
    pair<bool, vector<ll>> solve() {
        vector<ll> dist(n + 1, 0);
        vector<int> cnt(n + 1, 0);
        vector<bool> inq(n + 1, true);
        queue<int> q;
        for (int i = 1; i <= n; ++i) q.push(i);
        while (!q.empty()) {
            int u = q.front(); q.pop(); inq[u] = false;
            for (auto &e : g[u]) if (dist[e.to] > dist[u] + e.w) {
                dist[e.to] = dist[u] + e.w;
                if (!inq[e.to]) {
                    q.push(e.to); inq[e.to] = true;
                    if (++cnt[e.to] > n) return {false, {}};     // 负环 ⇒ 矛盾
                }
            }
        }
        return {true, dist};
    }
};
```

**用法示例**（P5960 差分约束模板）：

```cpp
// n 个变量，m 条 x_c - x_d <= y
// DifferenceConstraints dc(n);
// for each: dc.addLE(d, c, y);
// auto [ok, x] = dc.solve();
// if (!ok) puts("NO"); else for (i=1..n) print x[i];
```

**注意**：
- **求最小解**用最长路（`>=`），求最大解用最短路（`<=`）。上面是"最小化"的典型形式。
- 无解 ⇔ 负环。
- 输出要求"最小非负解"时，求完 `dist` 后整体平移：`x[i] -= min_j x[j]`。

## 4. 带权并查集判断"关系是否矛盾"★

**适用**：形如 `val[v] - val[u] = w` 的**等式**方程组，或"同类/异类"关系网，判断是否自相矛盾。

**核心公式**（一定要自己推一遍）：维护 `d[x] = val[x] - val[fa[x]]`，`find` 时累加。

合并时令 `fa[rv] = ru`，需要 `d[rv] = val[rv] - val[ru]`。
由 `val[v] - val[u] = w`、`val[v] = val[rv] + d[v]`、`val[u] = val[ru] + d[u]` 得：

```
val[rv] - val[ru] = w + d[u] - d[v]
```

```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;

struct EqCheck {
    vector<int> fa, rk;
    vector<ll> d;                      // d[x] = val[x] - val[fa[x]]

    explicit EqCheck(int n) : fa(n + 1), rk(n + 1, 1), d(n + 1, 0) {
        iota(fa.begin(), fa.end(), 0);
    }

    int find(int x) {
        if (fa[x] == x) return x;
        int f = fa[x];
        fa[x] = find(f);
        d[x] += d[f];                  // 累加到根的偏移
        return fa[x];
    }

    // 断言 val[v] - val[u] == w；矛盾返回 false
    bool assert_diff(int u, int v, ll w) {
        int ru = find(u), rv = find(v);
        if (ru == rv) return (d[v] - d[u]) == w;   // 已同类，直接校验
        if (rk[ru] < rk[rv]) { swap(ru, rv); swap(u, v); w = -w; }
        fa[rv] = ru;
        d[rv] = w + d[u] - d[v];
        if (rk[ru] == rk[rv]) ++rk[ru];
        return true;
    }

    // 查询 val[v] - val[u]（要求已合并）
    ll diff(int u, int v) { find(u); find(v); return d[v] - d[u]; }
};
```

**用法（区间和方程，P2294 狡猾的商人）**：
已知 `sum[l..r] = w`，用前缀和 `S[r] - S[l-1] = w`，把 `S` 当下标，直接用 `assert_diff(l-1, r, w)`；任一条返回 `false` 即"账本有假"。

## 5. 种类并查集判矛盾（拆点法）

**问题**："a 与 b 同类 / 不同类"，判断是否存在矛盾。
拆成 `2n` 个点：`x` 表示"x 属于第 0 类"，`x+n` 表示"x 属于第 1 类"。

| 断言 | 合并 |
|---|---|
| `x` 与 `y` 同类 | `x~y`，`x+n~y+n` |
| `x` 与 `y` 异类 | `x~y+n`，`x+n~y` |
| 矛盾判定 | `find(x) == find(x+n)` |

```cpp
#include <bits/stdc++.h>
using namespace std;

struct SplitDSU {
    vector<int> fa, rk;
    int n;

    explicit SplitDSU(int n_) : fa(2 * n_ + 2), rk(2 * n_ + 2, 1), n(n_) {
        iota(fa.begin(), fa.end(), 0);
    }
    int find(int x) { return fa[x] == x ? x : fa[x] = find(fa[x]); }
    bool unite(int a, int b) {
        a = find(a); b = find(b);
        if (a == b) return false;
        if (rk[a] < rk[b]) swap(a, b);
        fa[b] = a;
        if (rk[a] == rk[b]) ++rk[a];
        return true;
    }

    // 断言 x 与 y 同类；矛盾返回 false
    bool same_class(int x, int y) {
        if (find(x) == find(y + n)) return false;      // 已经异类
        unite(x, y);
        unite(x + n, y + n);
        return true;
    }
    // 断言 x 与 y 异类；矛盾返回 false
    bool diff_class(int x, int y) {
        if (find(x) == find(y)) return false;          // 已经同类
        unite(x, y + n);
        unite(x + n, y);
        return true;
    }
};
```

**用途**：P1892 团伙、P1525 关押罪犯（也可用二分图判定）、P2024 食物链（种类更多，用带权并查集更方便）。

## 6. 传递闭包判环（小图）

```cpp
#include <bits/stdc++.h>
using namespace std;

// Floyd 传递闭包 + 判环：存在 d[i][i] == true 即有环
vector<vector<bool>> closure(int n, const vector<pair<int,int>> &edges) {
    vector<vector<bool>> d(n + 1, vector<bool>(n + 1, false));
    for (int i = 1; i <= n; ++i) d[i][i] = true;
    for (auto [u, v] : edges) d[u][v] = true;
    for (int k = 1; k <= n; ++k)
        for (int i = 1; i <= n; ++i)
            if (d[i][k])
                for (int j = 1; j <= n; ++j) d[i][j] = d[i][j] || d[k][j];
    return d;
}
```

**bitset 优化**（`n <= 5000` 也能跑）：

```cpp
#include <bits/stdc++.h>
using namespace std;

template <int MAXN>
bool has_cycle_bitset(int n, const vector<pair<int,int>> &edges) {
    static bitset<MAXN> d[MAXN];
    for (int i = 1; i <= n; ++i) { d[i].reset(); d[i][i] = 1; }
    for (auto [u, v] : edges) d[u][v] = 1;
    for (int k = 1; k <= n; ++k)
        for (int i = 1; i <= n; ++i)
            if (d[i][k]) d[i] |= d[k];
    for (int i = 1; i <= n; ++i)       // 自身可达且不是自环，说明有环
        for (int j = 1; j <= n; ++j)
            if (i != j && d[i][j] && d[j][i]) return true;
    return false;
}
```

## 7. 常见"循环偏序"题型

| 题型 | 做法 |
|---|---|
| 给若干 `a < b`，问能否排成一列 | 拓扑排序 + 判环 |
| 给若干 `<=`，问最大/最小值 | 差分约束（最短路/最长路） |
| 给区间和，问一致性 | 带权并查集 / 差分约束 |
| "a 和 b 同类/异类" | 拆点并查集 |
| 2-SAT 有无解 | Tarjan SCC |
| 偏序关系是否传递一致 | 传递闭包 |
| "第 k 大/小"约束 | 差分约束 + 二分 |
| 有向图是否存在环 | `dfs` 三色标记 / 拓扑排序 |

**dfs 三色判环（有向图）**：

```cpp
#include <bits/stdc++.h>
using namespace std;

// 0=未访问, 1=在栈中, 2=已完成
struct CycleDetect {
    int n;
    vector<vector<int>> g;
    vector<int> color;
    explicit CycleDetect(int n_) : n(n_), g(n_ + 1), color(n_ + 1, 0) {}
    void addEdge(int u, int v) { g[u].push_back(v); }

    bool dfs(int u) {
        color[u] = 1;
        for (int v : g[u]) {
            if (color[v] == 1) return true;         // 回边 ⇒ 有环
            if (color[v] == 0 && dfs(v)) return true;
        }
        color[u] = 2;
        return false;
    }
    bool hasCycle() {
        for (int i = 1; i <= n; ++i)
            if (color[i] == 0 && dfs(i)) return true;
        return false;
    }
};
```

## 8. 小结

- **判"关系有没有矛盾"**：优先用**带权并查集 / 拆点并查集**（`O(n α)`，最好写）。
- **判"不等式组有没有解"**：**差分约束 + SPFA 判负环**。
- **判"排序/先后顺序有没有环"**：**拓扑排序**。
- **判"图里有没有环"**：有向图三色 DFS；无向图并查集/DFS 找返祖边。
- 一旦判出"有环/负环/矛盾"，题目通常要求输出 `NO` / `-1` / "Impossible"。

| 算法 | 思路一句话 | 用途 | 例题 |
|---|---|---|---|
| 拓扑排序判环 | 入度为 0 入队，出队数 < n 则有环 | 顺序矛盾 | P1113 杂务、P4017 |
| 反图 + 大根堆拓扑 | 从 n 倒着填，编号小的靠前 | 字典序最小拓扑序 | P1347 排序 |
| DAG 最长路 | 拓扑序上 DP | DAG 最长链 | P1807 最长路 |
| 差分约束 | `x_v - x_u <= w` → 边 `u->v` 权 `w`，SPFA 判负环 | 不等式组可行解 | P5960【模板】差分约束 |
| 带权并查集判等式 | `val[v]-val[u]=w`，矛盾即 false | 区间和一致性 | P2294 狡猾的商人 |
| 拆点并查集判异类 | `x~y+n, x+n~y` | 同类/异类矛盾 | P1892 团伙、P1525 |
| 三色 DFS 判环 | 1=在栈中，遇 1 即有环 | 有向图判环 | P1347 排序 |
| 传递闭包判环 | `d[i][i]` 为真即有环 | 小图判环 | P2419 |
| 2-SAT | SCC 判矛盾 | 布尔约束 | P4782 |

**判断顺序**：先看是不是"排序问题"（拓扑）→ 再看是不是"不等式"（差分约束）→ 再看是不是"同类/异类"（并查集）。
