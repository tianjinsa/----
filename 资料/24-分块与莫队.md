# 24 分块与莫队

> **分块**：把数组切成 `√n` 块，暴力 + 整块处理。**莫队**：离线 + 移动区间指针，用 `O(1)` 加入/删除元素。
> 这两个是"`O(n√n)` 暴力把 `O(n^2)` 题压过去"的利器，含金量高、好写。

---

## 1. 分块（区间加、区间和）

**原理**：块内维护 `lazy`（整块加），`sum`（块内和）；整块操作打标记，散块暴力。

```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;

struct SqrtDecomp {
    int n, B, nb;                         // nb = 块数
    vector<ll> a, sum, lazy;
    vector<int> belong;

    explicit SqrtDecomp(const vector<ll> &arr) {    // arr 下标 1..n
        n = (int)arr.size() - 1;
        B = max(1, (int)sqrt(n));
        nb = (n + B - 1) / B;
        a = arr;
        sum.assign(nb + 1, 0);
        lazy.assign(nb + 1, 0);
        belong.assign(n + 1, 0);
        for (int i = 1; i <= n; ++i) {
            belong[i] = (i - 1) / B + 1;
            sum[belong[i]] += a[i];
        }
    }

    void range_add(int l, int r, ll v) {
        int bl = belong[l], br = belong[r];
        if (bl == br) {
            for (int i = l; i <= r; ++i) a[i] += v, sum[bl] += v;
            return;
        }
        for (int i = l; i <= bl * B; ++i) a[i] += v, sum[bl] += v;
        for (int b = bl + 1; b <= br - 1; ++b) lazy[b] += v, sum[b] += v * B;
        for (int i = (br - 1) * B + 1; i <= r; ++i) a[i] += v, sum[br] += v;
    }

    ll range_sum(int l, int r) {
        int bl = belong[l], br = belong[r];
        ll res = 0;
        if (bl == br) {
            for (int i = l; i <= r; ++i) res += a[i] + lazy[bl];
            return res;
        }
        for (int i = l; i <= bl * B; ++i) res += a[i] + lazy[bl];
        for (int b = bl + 1; b <= br - 1; ++b) res += sum[b];
        for (int i = (br - 1) * B + 1; i <= r; ++i) res += a[i] + lazy[br];
        return res;
    }
};
```

**复杂度**：`O(√n)` 每次操作。

> **注意**：最后一块可能不满 `B`，`sum[b] += v * B` 那行对最后一块要特殊处理，上面的写法假设只有最后一块不满——更稳妥的写法是维护每块的实际长度 `blen[b]`。

**实例：P2801 教主的魔法** —— 区间加 + 区间统计 `>= x` 的个数（块内排序 + 二分）。


## 2. 莫队（离线区间查询）

**原理**：把所有询问按 `(l / B, r)` 排序（`l` 同块时 `r` 交替方向），用双指针在区间之间"移动"，每次移动 `O(1)` 更新答案。
**复杂度**：`O((n + m) √n)`。

### 2.1 普通莫队模板

**实例：P1972 [SDOI2009] HH 的项链**（区间不同数个数，可用莫队）

```cpp
#include <bits/stdc++.h>
using namespace std;

struct MoAlgo {
    struct Query { int l, r, id; };
    int n, m, B;
    vector<Query> qs;
    vector<int> a, cnt, ans;
    int cur = 0;                          // 当前答案

    MoAlgo(const vector<int> &arr, int m_) : n((int)arr.size() - 1), m(m_), a(arr) {
        B = max(1, (int)(n / sqrt(max(1, m_))));
        cnt.assign(n + 2, 0);
        ans.assign(m_, 0);
        qs.reserve(m_);
    }
    void addQuery(int l, int r, int id) { qs.push_back({l, r, id}); }

    void add(int pos) {                   // 加入第 pos 个元素
        if (cnt[a[pos]]++ == 0) ++cur;
    }
    void remove(int pos) {                // 删除第 pos 个元素
        if (--cnt[a[pos]] == 0) --cur;
    }

    vector<int> run() {
        sort(qs.begin(), qs.end(), [&](const Query &x, const Query &y) {
            int bx = x.l / B, by = y.l / B;
            if (bx != by) return bx < by;
            return (bx & 1) ? x.r > y.r : x.r < y.r;   // 奇偶优化
        });
        int L = 1, R = 0;
        for (auto &q : qs) {
            while (L > q.l) add(--L);
            while (R < q.r) add(++R);
            while (L < q.l) remove(L++);
            while (R > q.r) remove(R--);
            ans[q.id] = cur;
        }
        return ans;
    }
};
```

**关键点**：
1. 排序用 `(l / B, r)`，**`l` 同块时 `r` 奇偶交替**（常数优化约 2 倍）。
2. `B = n / sqrt(m)`（`m` 为询问数）通常最优。
3. `add/remove` 必须 `O(1)`（或用能快速回退的结构）。

### 2.2 带修莫队

**原理**：给每个询问加"时间"维度 `t`（第几次修改后），三个指针 `(l, r, t)` 一起移动。
**复杂度**：`O(n^(5/3))`。

**实例：P1903 [国家集训队] 数颜色 / 维护队列**

```cpp
#include <bits/stdc++.h>
using namespace std;

struct MoWithModify {
    struct Query { int l, r, t, id; };
    struct Modify { int pos, from, to; };
    int n, m, B;
    vector<Query> qs;
    vector<Modify> mods;
    vector<int> a, cnt, ans;
    int cur = 0;

    explicit MoWithModify(const vector<int> &arr) : n((int)arr.size() - 1), a(arr) {
        B = max(1, (int)pow(n, 2.0 / 3.0));
        cnt.assign(n + 2, 0);
    }
    void addQuery(int l, int r, int t, int id) { qs.push_back({l, r, t, id}); }
    void addModify(int pos, int from, int to) { mods.push_back({pos, from, to}); }

    void add(int pos) { if (cnt[a[pos]]++ == 0) ++cur; }
    void remove(int pos) { if (--cnt[a[pos]] == 0) --cur; }

    void apply(int idx, int l, int r) {    // 应用第 idx 个修改
        auto &md = mods[idx];
        if (l <= md.pos && md.pos <= r) { remove(md.pos); a[md.pos] = md.to; add(md.pos); }
        else a[md.pos] = md.to;
    }
    void undo(int idx, int l, int r) {
        auto &md = mods[idx];
        if (l <= md.pos && md.pos <= r) { remove(md.pos); a[md.pos] = md.from; add(md.pos); }
        else a[md.pos] = md.from;
    }

    vector<int> run() {
        sort(qs.begin(), qs.end(), [&](const Query &x, const Query &y) {
            if (x.l / B != y.l / B) return x.l / B < y.l / B;
            if (x.r / B != y.r / B) return x.r / B < y.r / B;
            return x.t < y.t;
        });
        ans.assign(qs.size(), 0);
        int L = 1, R = 0, T = 0;
        for (auto &q : qs) {
            while (T < q.t) apply(T++, L, R);
            while (T > q.t) undo(--T, L, R);
            while (L > q.l) add(--L);
            while (R < q.r) add(++R);
            while (L < q.l) remove(L++);
            while (R > q.r) remove(R--);
            ans[q.id] = cur;
        }
        return ans;
    }
};
```

### 2.3 树上莫队（欧拉序）

**原理**：把树转成欧拉序（每点进/出各记一次），路径 `u-v` 转成区间；出现两次的点不算。
**典型题**：P4074 [WC2013] 糖果公园、SP10707 COT2。

```cpp
// 关键：欧拉序 euler[1..2n]，st[u]/ed[u] 为进/出位置
// 路径 u-v（设 st[u] < st[v]）：
//   若 lca(u,v) == u：区间 [st[u], st[v]]
//   否则：区间 [ed[u], st[v]] 再单独加上 lca
// 区间内某点出现奇数次才计入答案
```

### 2.4 回滚莫队（只加不删）

**原理**：当"删除"很难实现时，用回滚（只保留加入操作，用栈记录并撤销）。适用于"最大值"这类不可减的信息。
**典型题**：P5906【模板】回滚莫队、P4137 Rmq Problem / mex。


## 3. 分块 vs 莫队 vs 其他

| 需求 | 方法 | 复杂度 |
|---|---|---|
| 区间加/区间和 | 分块 / 线段树 | `O(√n)` / `O(log n)` |
| 区间加/区间第 k 小 | 分块 + 块内排序 | `O(√n log n)` |
| 静态区间众数 | 分块 | `O(n√n)` |
| 离线区间不同数 | 莫队 | `O(n√n)` |
| 带修区间不同数 | 带修莫队 | `O(n^(5/3))` |
| 树上路径查询 | 树上莫队 | `O(n√n)` |
| 只增不删的区间 | 回滚莫队 | `O(n√n)` |
| 区间最值（静态） | ST 表 | `O(1)` |
| 可离线二维偏序 | CDQ | `O(n log^2 n)` |

**选择建议**：
1. 能线段树就线段树（`O(log n)` 更快）。
2. 信息**不可合并**（如众数、不同数个数）→ 莫队/分块。
3. 强制在线 → 分块/树套树，莫队不行。

## 4. 莫队常见坑

1. **`remove` 时先改 `cnt` 再判断**，顺序反了会错。
2. **奇偶排序**能省一半常数，别忘了。
3. **离散化**：莫队通常需要把值域压到 `n` 以内。
4. **多测**要清空 `cnt` 和 `cur`。
5. **带修莫队**的 `apply/undo` 里 `l <= pos <= r` 判断不能漏。
6. **块长**：普通莫队 `n/√m`，带修 `n^(2/3)`。


### 怎么用（照抄这段 `main`，只改【输入】【输出】两处）

上面是模板本体。实际写题时：**把上面的 struct 整段粘过来 → 再粘这段 `main` → 只改标了【输入】【输出】的行**。

```cpp skip
#include <bits/stdc++.h>
using namespace std;

// ===== 粘贴点：把上面的 MoAlgo 粘到这里 =====

int main() {
    // ===================== 【输入】改这里 =====================
    int n, m;
    scanf("%d %d", &n, &m);               // n 个数，m 次询问
    vector<int> a(n + 1);
    for (int i = 1; i <= n; ++i) scanf("%d", &a[i]);
    // ========================================================

    // ===================== 【核心】算法流程 =====================
    // 莫队 = 离线 + 双指针
    //   1) 把所有询问按 (l / 块长, r) 排序，块长 ≈ n / sqrt(m)
    //   2) 维护当前区间 [L, R]，把 L/R 一步步挪到目标区间
    //   3) 每次挪动只增/删一个元素，用 add(pos) / remove(pos) 更新答案
    // 换题时只需要改写 add / remove 两个函数，其余不动
    MoAlgo mo(a, m);
    for (int i = 0; i < m; ++i) {
        int l, r;
        scanf("%d %d", &l, &r);
        mo.addQuery(l, r, i);
    }
    vector<int> ans = mo.run();
    // ========================================================

    // ===================== 【输出】改这里 =====================
    for (int i = 0; i < m; ++i) printf("%d\n", ans[i]);
    // ========================================================
    return 0;
}
```
